# feedback.md

## iExec Tools Feedback (WTF Hackathon)

### Confidential Smart Contracts Wizard
- Bagus untuk bootstrap arsitektur awal dan mempercepat onboarding.
- Akan lebih membantu jika ada template "feature parity migration" dari protokol publik ke confidential wrapper.

### Nox docs
- Struktur dokumentasi sudah cukup jelas untuk getting started.
- Akan lebih efektif bila ada satu contoh end-to-end yang lengkap: frontend -> encrypted input -> Nox execution -> route ke protokol publik (mis. Uniswap) -> hasil ke UI.

### Nox packages / plugin
- Packaging membantu standardisasi setup.
- Ke depan, contoh repo dengan baseline test + deployment Sepolia yang lebih opiniated akan mengurangi trial-and-error di fase awal.
